## Setup

Python 3.10 or later is recommended.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

Run all demonstrations:

```bash
python run_all.py
```

Or run an individual question:

```bash
python q1_reward_demo.py
python q2_reinforce.py
python q3_actor_critic.py
python q4_ppo.py
python q5_ddpg.py
```

Outputs are saved in `results/`. Training curves and CSV logs are generated by execution; do not report values as measured until you run the code and inspect the output.

## Notes and academic honesty

- The scripts are educational, compact implementations intended to make the algorithms easy to inspect.
- `q3_actor_critic.py` implements a single-process synchronous Actor–Critic/A2C-style learner. It is **not** a true multi-process A3C implementation. The README and report should not claim otherwise.
- TRPO is explained in the report but not implemented as a full constrained optimizer in this compact repository. PPO is implemented.
- DDPG is demonstrated on a small continuous-control navigation task, while the original maze uses four discrete actions.
- Run each script yourself, retain your own console output, and add genuine screenshots and measured results before submission.
- Both partners should execute and understand all questions, as required by the assignment.
