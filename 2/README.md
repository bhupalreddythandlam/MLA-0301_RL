# MLA03 – Reinforcement Learning | Assignment 2 (CO2)

**Project:** Intelligent Autonomous Warehouse Robot Navigation and Path Optimization

This repository contains runnable Python implementations and supporting explanations for all five tasks in the assignment. The baseline simulation uses a 5×5 warehouse grid, NumPy and tabular reinforcement learning.

## Features

- **Task 1:** Warehouse MDP definition, transition model, reward design, policy evaluation/improvement, policy iteration and value iteration.
- **Task 2:** Policy Iteration, Value Iteration, Monte Carlo prediction and the completed three-state Value Iteration exercise.
- **Task 3:** First-Visit and Every-Visit Monte Carlo prediction, ε-soft Monte Carlo control and TD(0), including the assignment's numerical example.
- **Task 4:** SARSA and Q-Learning implementations, update-equation numerical examples, plus DQN/DDQN/Dueling DQN/PER notes.
- **Task 5:** Integrated warehouse simulation, final path display, comparison of Value Iteration, SARSA and Q-Learning, CSV results and performance graph.

## Warehouse setup

- Grid: 5 rows × 5 columns
- Start: `(0, 0)`
- Goal / packing station: `(4, 4)`
- Obstacles: `(1, 1)`, `(1, 3)`, `(2, 3)`, `(3, 1)`
- Actions: Up, Down, Left, Right
- Reward: +100 at the goal, −10 for an obstacle or invalid move, and −1 for an ordinary move
- Discount factor: `γ = 0.90`

The environment is deterministic in this baseline implementation. An attempted move into an obstacle or outside the grid leaves the robot in its current cell and applies a penalty.

## Reproducibility

The experiment uses fixed random seeds. The training episode count and learning parameters are defined near the top of `task5_warehouse_project.py`. Results are generated by running the code; do not manually edit the generated metrics or graph.
